# 水系生活圈与亭林休闲 Implementation Plan

> Execution: use executing-plans for step-by-step work; ordinary isolated subagents in this session, followed by independent review.

**Goal:** 落地用户两组获准的观赏型生活场景，岸观水下、轻交互识物，无潜水背包经营或完整棋局。

**Architecture:** Three additive deterministic scene factories return group, blockers, targets, stations, layout, update(dt, elapsed, sky), getStats and dispose. A separate community-life actor module consumes successful stations, preserving original people list and story roles. Existing sky registers all new materials, paused loop advances none, sound uses existing audio master and gesture unlock.

**Tech Stack:** Existing Three.js ESM and Vite; no dependency, new server, deployment, Git initialization or save schema changes. Exact current baseline under .visual-round6-baseline.

---

## Shared contracts
Factories createPondLife(options), createWaterworks(options), createLeisureGrove(options) receive world, field, distanceToRiver, riverCurve, stream, flora, village, props, hinterland, villageScenes, villageLife, mysteryWorld, boats, cliff, exterior, habitatDetails, reservations (earlier round6 factories). No source or RNG mutation. Structures avoid roads, doors, original/reserved plot paths, moorings, cliffs, mystery and quiet stops. Actual field/render floor sampled, wet and dry distinguished. Each successful target {id,x,y,z,range,resolve?} belongs to visible constructed geometry. stations [{kind,x,y,z,yaw,path?,prop?}] only successful safe anchor placements. Station kinds wash,trap,elder,child-grass,child-stones,child-top,beekeeper,liubo. Paths explicitly prevalidated; no teleport-through-obstacles. New blockers are appended before barrier and original people constructor. Pillar/tree/post blockers precise; never block whole gazebo interiors. Keep original water/sky colors and old world.json byte-identical.

## Task 1: pond ecology (pond owner)

Return wash stations for actor owner.

## Task 2: waterworks (water owner)
Create src/world/waterworks.js and scripts/check-waterworks.mjs. Write failing tests then implement waterline-accurate bamboo timber wheel, bucket discharge, connected descending bamboo irrigation into a new visibly planted small dry-bank grain bed (verified original river cannot reach existing basin fields across cliff/story portal without violating protected routes); rotary cam/lever and mortar, shared mechanical phase and one impact per cycle; V stone weir with open downstream trap throat and woven inward-cone fish basket. Water animation demonstrative, not fluid simulation. Do not invent new river confluence or alter terrain. Add local visible modest intake/race for existing near-level stream, no floating fake waterfall. Expose trap station and geometry prop for lift. <=11000 triangles <=14 draws.

## Task 3: leisure landscape (grove owner)
