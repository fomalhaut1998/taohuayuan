# 第四轮实施计划：识物、层次与一日天色

依据用户批准的方案实施，不另起服务器、不新增依赖、不改故事流程或旧存档键。精确原文件已保存在 `.visual-round4-baseline/`。

## 体验与验收

- 靠近并看向场景中实际存在的对象才显示一个轻量名称标记；距离、视锥、地形和建筑遮挡都有效。G 打开插画式小图鉴并记入原手记，E 继续原互动。只看不自动收集；开关图鉴有焦点归还、Esc 和暂停，不干扰 J/M/输入框。兼容原九种图鉴记录与旧存档。
- 林下、岸边、村边分别补蕨草/灌丛/枯枝、石簇/水生植物/岸边沉积、农作与生活细节；成组留白，不以均匀撒点替代设计。只接受实际干地和安全坡面；保护旧树、舟绳、路径、住宅门前、人物路线、洞口与可见奖励。新增物件可识别，只有真实几何对应的条目。
- 3D 从白天自然蓝天绿地过渡到暖暮色与冷静月色，保留夜窗暖光；水、植被和受光一致，而非全屏滤镜。M 大地图和小地图同步游戏天时过渡纸色、墨色、水色、图标和文字对比度，不修改探索记录、目的地、缩放和相机。
- 保留旧全套回归并新增真实模块测试，检查目录存档兼容、遮挡与 G/E 优先级、几何边界与安全、材质颜色、静态优化契约、日夜连续过渡/缓存与无配置突变。最后真实浏览器同位置截图、识别/图鉴/大小地图操作、GL 程序和渲染开销核对。隐藏页面不报告前台 FPS，不把未主观试听或走遍当成完成。

## 并行文件责任

1. 识物与图鉴工程师：`src/systems/observation.js`、`src/systems/journal.js` 和新的 catalogue/discovery/field-guide 模块及专用 CSS、新测试。保留旧导出和存档键；给队长 `createDiscovery(options)` 接口以及初始化源数据需求。不得编辑 main、世界配置、地图或旧全局样式。
2. 环境工程师：新的 `src/world/habitat-details.js`、可选配套几何模块和 `scripts/check-habitat-details.mjs`。工厂输入现有世界/地形/距离/布局引用，输出 group、识物 targets、layout、getStats/dispose；不改原生成器、RNG、碰撞或路径。预算至多 6500 新三角形、3 个静态不透明批次；至少三个区域、视觉成组；实测安全与预算。
3. 场景天色工程师：仅 `src/systems/sky.js`、必要新的纯函数模块与新回归；调查并修复 3D 受光/水/植被的一致过渡。不改 world 配置、main 或地图；保留晴天蓝天及既有天气/夜空/冻结测试与公共 API。需要配置调整先向队长交精确建议，不直接改配置。
4. 地图天色工程师：仅 `src/systems/map.js`、`src/systems/mapdraw.js`、新主题模块/专用 CSS 和新回归。为地图提供 `setTimeAppearance(timeId, dt, weatherId)`（或同等明确接口），地图自身 `update` 按天时连续变化，保留缩放/目的地/访问/点击/键盘逻辑。缓存大底图，不逐帧重烘焙。不得改 main、sky、world 或旧 style.css。
5. 队长：主入口集成、世界配置必要增量、静态优化器的精确新根/名称、安全全局暂停与 G 集成、集成测试；未分配文件不得越权并行编辑。

## 顺序与验证

1. 完整备份、规划 → 四个独立工作包同时开始。
2. 队长读入口/控制/静态优化/旧测试，准备集成与浏览器同位置旧图；工作包交付时逐个读源集成。
3. 每个作者先运行自己新测试和受影响旧测试，报告真实结果、变更路径、配置建议和接口。
4. 队长运行 `node scripts/check-*.mjs` 与 `node scripts/test-*.mjs` 的逐脚本全套及 `node scripts/check-sampled-audio.mjs --assets`，执行 `npm run build`。非零先调查。
5. 在现有 `http://127.0.0.1:4173` 检查编译后真实画面、识物图鉴/遮挡、大小地图三时段、现有 J/M/E/G、程序链接与开销。截图来自实际 WebGL/DOM，不生成示意图冒充。
6. 独立只读审阅最新实现与基线及证据 → 真问题修复和相关复验 → 独立第四轮报告与图像交付；旧轮报告保持历史原样。

不自动部署。性能既有压力视角已超 50 万三角形、FPS 未实测，须如实分开说明新增预算与全场景指标。
