# 村景丰富化与古风彩蛋

## 用户确认
继续丰富元素，不局限于《桃花源记》原文景物；保留淡雅低多边形画风。彩蛋采用古风奇趣、略神秘方向，不用现代梗。

## 实现边界
- 生活成景：茶歇棚与茶具、晾衣柴院、陶窑器物陈列；自然层次用野花、倒木、蕨草等组合，不再只增加树。无适宜水岸不强行摆水车。
- 彩蛋：林边古钟、苔石残棋、暮夜流萤。提供真实声音/摆动/微光等克制反馈，不设任务箭头、完成率或新收藏清单。
- 既有村道、房门、田地、村民路线及外围道路保持净空，实际玩家半径0.42。所有新实心障碍先汇总再创建barrier，镜头/人物/互动共用。
- 新可见生活景物通过真实mapData绘入舆图；彩蛋不作剧透标记。
- E键统一候选仲裁，每次最多一个对象；保留无锁键盘漫游，弹窗/表单/修饰键/后台/隐藏界面不触发彩蛋。
- 合批与确定性布局，常驻几何预算明确；不新增服务、依赖、提交或推送。

## 分工
生活与自然：src/world/village-scenes.js、src/data/village-scenes.json、src/systems/mapdraw.js及专用测试。
彩蛋与主线集成：src/world/mysteries.js、src/systems/mysteries.js、src/main.js、interaction/sound及必要DOM样式和专用测试。
主会话：接口/净空交叉复核，独立回归，统一build与真实截图核验，处理发现问题。

## 验证
新模块几何有限与预算、布局确定性、避水崖田房与旧新道路、0.42通行及交互可达；E键仲裁/遮挡/UI输入边界/时天条件/冷却/暂停。执行既有check-village-models、check-village-props、check-characters、test-hinterland及新增测试，最后npm run build。已有4173预览中核对实际资源hash、成景近远景与舆图、古钟/残棋/流萤反馈、控制台；仅实际覆盖内容可报告，后台静态截图不等于前台游玩或性能测试。
